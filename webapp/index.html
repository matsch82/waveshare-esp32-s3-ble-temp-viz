Der Uhr-Dienst ist nur in den ersten 5 Minuten nach dem Einschalten erreichbar (oder nachdem BOOT 5 Sekunden gedrückt wurde). Danach schläft das Thermometer.

So startest du die Seite

  1. Im Terminal in den Ordner webapp wechseln und python3 -m http.server starten.
  2. In Chrome oder Edge http://localhost:8000 öffnen.
  3. Thermometer einschalten, auf „Verbinden“ klicken und „EPD-Uhr“ auswählen.
  4. „Uhrzeit übertragen“ klicken.

Web Bluetooth gibt es in Chrome und Edge auf dem Desktop und in Chrome unter Android. Safari und Firefox unterstützen es nicht, auf iPhone und iPad geht es nur mit der App Bluefy. Fürs Handy muss die Seite über https erreichbar sein (z. B. GitHub Pages).
